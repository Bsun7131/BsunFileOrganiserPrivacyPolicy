Bsun File Organiser — Privacy Policy

Last updated: 8 October 2026

Developer: Bisan Subba

Overview

Bsun File Organiser is a Windows desktop utility developed using Python and Tkinter. It allows users to organise files into folders based on their file types.

The application is designed to process files locally on the user's computer.

Information Access and Processing

Bsun File Organiser accesses files and folders selected by the user for organisation.

The application uses file names, paths and extensions to categorise and move files into appropriate folders.

Files remain on the user's computer and are not uploaded to the developer or any external server.

Data Collection

Bsun File Organiser does not collect personal information for the developer.

The application does not use user accounts, analytics, advertising, tracking technologies or online data collection services.

Data Storage and Security

All file organisation operations are performed locally on the user's device.

The application creates category folders and moves files according to their extensions. It does not maintain an online database or transmit file information to external services.

Users remain responsible for managing and backing up their files.

Third-Party Data Sharing

Bsun File Organiser does not sell, share or transmit user files or personal information to third parties.

User Control

Users choose which folders to organise. The application operates on the selected files and folders.

File changes made by the application remain on the user's computer unless the user subsequently changes them.

Children's Privacy

Bsun File Organiser does not knowingly collect personal information from children or other users.

Changes to This Privacy Policy

This privacy policy may be updated to reflect changes to the application's features or privacy practices. Any updates will be published on this page.
